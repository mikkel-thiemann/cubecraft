# SwissCraft

Ein Minecraft-ähnliches Spiel, das direkt im Browser läuft – mit Crafting-Rezepten wie im Original.

**Spielen:** https://mikkel-thiemann.github.io/cubecraft

Steuerung: WASD laufen, Leertaste springen, Maus schauen, Linksklick abbauen, Rechtsklick bauen, E Inventar, 1–9 Schnellleiste.
Braucht Tastatur und Maus (PC/Laptop).

Fan-Projekt, nicht offiziell und nicht von Mojang.
